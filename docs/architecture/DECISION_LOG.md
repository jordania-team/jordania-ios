# Decision Log

**Purpose:** Immutable record of significant architectural and technical decisions, the context in which they were made, the options considered, and the rationale for the choice.

**Scope:** Decisions only — not guidelines or rules. Rules derived from decisions live in [ENGINEERING_RULES.md](ENGINEERING_RULES.md). This log is append-only; past entries are never modified.

## Format

Each entry follows this template:

```
### ADR-NNN — Title
**Date:** YYYY-MM-DD
**Status:** Accepted | Superseded by ADR-NNN
**Context:** ...
**Options Considered:** ...
**Decision:** ...
**Consequences:** ...
```
